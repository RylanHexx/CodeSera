⬡ Welcome to CodeSera
🔑
1. Add your API Key
Click 🔑 API Keys in the top-right. Paste your key from OpenRouter, Gemini, ChatGPT or any supported provider. Free options: Gemini Flash or Groq.
🎓
2. Generate a course
Type what you want to learn (e.g. "Teach me Python"), set your level, then hit Send. Lessons are generated and saved automatically.
✨
3. Customize (optional)
Use ✨ to turn on Newbie mode, heavy code, analogies and more. Use 🎯 to set a target like "web development" for tailored examples.
📖
4. Open lessons
Click Open on any lesson. Inside each lesson you'll find a 💬 chat button for questions and 🤖 Tell me more to expand any section.
🛠️ Projects —

Hands-on projects tailored to your course level. Click any project to generate a full guided lesson.

🧠 Quiz —

Select a lesson to start a quiz. AI generates unique questions each time.
